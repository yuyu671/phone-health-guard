手机健康助手 · 使用手册

一款给家里老人用的用机时长守护工具：用得太久自动锁屏休息，休息结束自动恢复。

适用系统：Android 7.0 及以上 · 默认 40 分钟上限 / 15 分钟休息

一、它能做什么

  • 限制连续使用时长：亮屏使用累计达到上限后，手机立即锁屏。
  • 强制休息：休息期间每次解锁，停留片刻后会被再次锁定，倒计时结束才彻底放开。
  • 自动恢复：休息结束后本轮计时清零，可以继续正常使用。
  • 不影响基础功能：接打电话、来电响铃、收发短信、闹钟全程不受影响。
  • 紧急拨号：锁屏页留有按钮，点击后可自由拨号 5 分钟。
  • 家属远程管理：同一个 WiFi 下，用手机浏览器就能查看状态、临时解锁、改设置。

二、第一次安装（约 5 分钟）

  1. 安装应用 把 手机健康助手.apk 传到老人手机上，点击安装。系统提示"未知来源"时选择允许。
  2. 激活设备管理器 打开应用，点「激活设备管理器（重要）」，在系统弹窗里点「激活」。这是自动锁屏的必要条件，只授予"强制锁屏"一项能力，不会清除任何数据。
  3. 允许悬浮窗 点「开启悬浮窗提醒」，在系统页面里打开开关。没有它，休息时只会发通知，看不到全屏倒计时。
  4. 允许通知 Android 13 及以上的手机，点「开启通知」并允许。通知栏会常驻一条守护状态，点击可打开应用。
  5. 忽略电池优化 点「忽略电池优化」，选择允许。否则系统可能在后台把守护进程清掉。
  6. 设置规则 在「守护规则」里调整单次使用上限（10–120 分钟）和休息时长（5–60 分钟）。默认是 40 分钟和 15 分钟，一般不用改。
安装完成后可以隐藏图标 应用首页底部有「隐藏桌面图标」，点一下老人就找不到它了，避免误卸载。以后要打开应用，下拉通知栏点「手机健康助手」那条通知即可。

三、让后台不被系统清理（重要）

国产手机默认会清理后台，必须手动放行一次，否则守护会失效。

品牌需要打开的设置
华为 / 荣耀 设置 → 应用和服务 → 应用启动管理 → 找到「手机健康助手」→ 改为手动管理，把「允许自启动」「允许关联启动」「允许后台活动」全部打开。
小米 / Redmi 设置 → 应用设置 → 应用管理 → 手机健康助手 → 自启动（开）；省电策略选「无限制」；同时允许「后台弹出界面」。
OPPO / 一加 / realme 设置 → 应用管理 → 自启动管理 → 允许；电池 → 后台运行 → 允许后台活动。
vivo / iQOO 设置 → 应用与权限 → 自启动 → 允许；电池 → 后台耗电管理 → 允许后台高耗电。
三星 设置 → 应用程序 → 手机健康助手 → 电池 → 允许后台活动；电池 → 后台使用限制 → 从不休眠的应用里加入。
魅族 设置 → 应用管理 → 手机健康助手 → 权限管理 → 自启动（开）。
加分项：锁定后台 打开最近任务界面，下拉「手机健康助手」的卡片，出现小锁图标即表示已锁定。这样"一键清理"不会把它清掉。

四、老人会看到什么

正常使用时

没有任何弹窗干扰，通知栏常驻一条使用时长状态。

达到上限时

手机立即锁屏。老人唤醒解锁后，会看到全屏提示：

  • 大标题「手机运行内存不足」
  • 副标题「后台程序有点多，手机正在自动清理」
  • 清理完成倒计时（例如 14:32）
  • 一行提醒：休息一下：起身走走、喝口水、看看窗外
  • 一个「紧急拨号」按钮

首次解锁可以停留约 20 秒，之后每次解锁约 8 秒，随后自动锁回，直到倒计时结束。

界面上不会出现"防沉迷""限制""守护软件"等字样 锁屏提示与通知都统一表述为"运行内存不足、正在自动清理"，避免老人把它当成管控软件后要求关闭。

需要打电话时

点「紧急拨号」，手机进入 5 分钟自由期：拨号、通话、挂断都不受限制。通话过程中会自动续期，挂断后仍有 5 分钟缓冲。

休息结束时

手机不再锁定，本轮计时清零，重新开始累计。

五、家属远程管理

手机和你的设备连在同一个 WiFi 时，用浏览器就能管理，不需要安装其他软件。

第一步：找到地址

打开应用（下拉通知栏点「手机健康助手」那条通知），在「远程控制」卡片里会看到一行地址，形如：

http://192.168.10.45:8899/?key=662704

密钥已经包含在链接里，直接点开或复制到浏览器即可。

第二步：在浏览器操作

打开后可以看到状态卡片和几个按钮：

功能说明
查看状态守护是否开启、本轮已用多久、今日累计、休息还剩多少、远程解锁还剩多少，每 3 秒自动刷新。
临时解锁提供 15 / 30 / 60 分钟三个按钮。点击后即使超过上限也不会锁屏，到点自动恢复限制。
修改设置填写新的上限和休息时长后点「保存设置」，立刻生效。
开启 / 暂停守护暂停后立即解除锁定，适合老人身体不适或临时需要长时间用手机的场景。
使用前提 只能在同一个局域网内访问。手机换了 WiFi 后 IP 地址会变，需要重新打开应用查看新地址。密钥错误时页面会提示，无法操作。

六、想打开应用，但桌面没有图标

如果已经点了「隐藏桌面图标」，有两种方式打开：

  1. 下拉通知栏，点击「手机健康助手」常驻通知，直接进入应用首页。
  2. 用电脑连接手机后执行命令（需要一点技术基础）：
adb shell am start -n com.anxin.guard/.MainActivity

需要临时把图标放回桌面时：

adb shell am broadcast -a com.anxin.guard.SHOW_LAUNCHER

七、常见问题

Q：老人说手机被锁了，打不了电话怎么办？
点锁屏页上的「紧急拨号」，5 分钟内可自由通话；也可以直接按电源键点亮屏幕接听来电，来电界面不受限制。家属还可以用远程控制临时解锁。
Q：今天想让老人多玩一会儿？
用远程控制页面点「临时解锁 60 分钟」，或者点「暂停守护」。到时间后记得重新开启。
Q：关机重启后还会生效吗？
会。应用注册了开机自启，重启后会自动恢复守护。前提是第三节的后台设置已经打开。
Q：老人把应用卸载了怎么办？
隐藏图标后普通人找不到入口，但能通过应用管理找到并卸载。如果反复出现，需要更强的管控方式（把手机设为设备所有者），代价是必须恢复出厂设置。
Q：换了新手机怎么迁移？
在新手机上重新安装 APK，按第二节的步骤重新配置一次即可。旧手机上的应用直接卸载，不会留下占用空间。
Q：会不会影响短信、微信、闹钟？
不会。锁定只作用于屏幕，后台的消息接收、闹钟提醒、来电响铃都正常。只是休息期间无法操作手机。
Q：远程页面打不开？
依次检查：两台设备是否连同一个 WiFi；地址里的 IP 是否是最新的；应用是否在运行（通知栏有常驻通知）；路由器是否开启了 AP 隔离（部分路由器会阻止设备互访）。

八、默认参数与安全说明

项目默认值
单次连续使用上限40 分钟（可调 10–120）
休息时长15 分钟（可调 5–60）
计时条件仅亮屏且非通话时累计
首次解锁停留约 20 秒
重复解锁停留约 8 秒
紧急拨号自由期5 分钟
远程控制端口8899（仅局域网）

安全边界

  • 只申请设备管理器的「强制锁屏」能力，不具备清除数据、重置密码、限制相机等权限。
  • 不申请无障碍、root 或设备所有者权限，不修改系统设置。
  • 不联网上传任何使用数据；远程控制只在本机局域网内监听，所有请求都需密钥。
  • 老人可以在系统设置里停用设备管理器或强制停止应用，这是普通应用无法阻止的边界。
