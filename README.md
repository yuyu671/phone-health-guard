# 手机健康助手 · 老年人用机时长守护

一个面向安卓手机的用机时长守护工具：累计亮屏使用达到上限后，手机会自动锁屏；休息倒计时结束前，每次解锁都会被立即重新锁定，倒计时结束后恢复正常使用。语音通话、来电、短信与闹钟全程不受影响。

## 一、直接打开构建

1. 用 Android Studio（Giraffe 及以上）打开本目录，等待 Gradle Sync。
2. 本项目需要 JDK 17、Android SDK 34（compileSdk/targetSdk=34，minSdk=24，Android 7.0 起可装）。
3. 若提示缺少 Gradle Wrapper，任选其一：
   - 在 Android Studio 里点报错提示的 Quick Fix（Create Gradle wrapper）；
   - 或本机装过 Gradle 时执行 `gradle wrapper --gradle-version 8.7`。
4. 运行 `app` 模块，或 `Build > Build Bundle(s)/APK(s) > Build APK(s)` 出安装包。

## 二、使用步骤（给家里老人装一次即可）

1. 打开应用 → 点「激活设备管理器（重要）」，在系统弹窗里点「激活」。这是自动锁屏的必要条件；只申请了「强制锁屏」一项能力，不会清除数据。
2. 授予「悬浮窗」权限，用于全屏显示休息倒计时；没有该权限时只弹通知。
3. Android 13+ 再授予「通知」权限；顺手点「忽略电池优化」，避免后台被杀。
4. 首页可调两件事：单次连续使用上限（10–120 分钟）、休息时长（5–60 分钟）。
5. 保持「开启守护」打开即可，重启手机后会自动恢复。

## 三、局域网远程控制（给家属用）

手机与家属的设备连在同一个 WiFi 时，用浏览器就能管理，不需要服务器、账号或云服务：

1. 打开应用首页，在「远程控制」卡片里会显示形如 `http://192.168.1.5:8899/?key=662704` 的地址。
2. 用家里另一台手机或电脑的浏览器打开该地址（密钥已带在链接里）。
3. 页面上可以：
   - 查看守护状态、本轮已用时长、今日累计、休息剩余时间；
   - 临时解锁 15 / 30 / 60 分钟（期间即使超过上限也不锁屏，到点自动恢复）；
   - 修改单次使用上限（10–120 分钟）与休息时长（5–60 分钟）；
   - 暂停或重新开启守护。
4. 所有接口都校验 `key`，密钥错误返回 403。密钥随机生成，保存在应用私有配置里。

注意：只能在同一个局域网内访问；手机换 WiFi 后 IP 会变，重新打开首页查看新地址即可。

## 四、工作方式

| 阶段 | 行为 |
| --- | --- |
| 正常使用 | 每 5 秒累计一次屏幕点亮时长；息屏、通话中都不计时 |
| 达到上限 | 立即锁屏，全屏显示「手机运行内存不足」与清理倒计时（善意的表述，避免被当作管控软件），期间不计时 |
| 休息期间 | 用户解锁后先停留 20 秒（首次）或 8 秒（再次解锁），期间显示全屏倒计时与「紧急拨号」；缓冲结束若仍在休息期就再次锁定 |
| 休息结束 | 停止锁屏，本次时长归零，重新开始一轮计数 |
| 关闭开关 | 立即结束本轮锁定，重新计时 |

## 五、为什么能做到"解锁后又锁上"

- 通过设备管理器（DeviceAdmin）调用系统 `lockNow()` 锁屏，不使用无障碍服务，也不申请 root；
- 服务动态监听 `ACTION_USER_PRESENT`（用户解锁）与 `ACTION_SCREEN_ON`，发现仍处于休息期就再次锁屏，直到倒计时结束；
- 这是普通应用的权限边界：无法阻止用户按电源键唤醒，也无法阻止用户去系统设置里停用设备管理器，只能做到"解一次、锁一次"。

## 六、通话 / 短信为何不受影响

- 服务每秒读取一次 `AudioManager.mode`，检测到 `IN_CALL / IN_COMMUNICATION / RINGTONE` 时：暂停计时、暂停锁屏、立即隐藏全屏提醒，挂断后自动恢复；
- 来电界面天然优先于悬浮窗，接听、挂断都不受限制；
- 全屏提醒页留有「紧急拨号」入口，点击后进入 5 分钟宽限期：期间完全不锁屏、不弹提醒，既能拨号也能接挂电话；通话过程中会持续续期，挂断后仍保留 5 分钟缓冲；
- 锁屏只影响屏幕，不影响短信接收、闹钟和后台通信。

## 七、快速验证（不用等 40 分钟）

把「单次连续使用上限」拖到 10 分钟、「休息时长」拖到 5 分钟，然后：

1. 保持亮屏使用，状态卡里的分钟数逐步上升；
2. 10 分钟后手机自动锁屏，唤醒后看到全屏倒计时；
3. 尝试解锁，首次会看到全屏倒计时，约 20 秒后才再次锁定；点「紧急拨号」可进入 5 分钟宽限期，期间不锁屏；
4. 5 分钟后唤醒，可正常进入桌面；
5. 期间打一通电话，验证休息期间仍能正常接打。

## 八、已知限制

- 必须先激活设备管理器，否则只能显示全屏提醒，无法锁屏。
- 用户可以在系统设置中停用设备管理器或强行停止本应用，这是普通应用无法阻止的；如需彻底防绕过，需要把手机设为设备所有者（Device Owner），会要求恢复出厂设置，不适合日常使用。
- 部分厂商（华为、小米、OPPO、vivo）的省电策略可能杀掉后台，建议同时在系统设置里允许自启动、锁定后台。
- 手机未设置锁屏密码时，唤醒后可短暂进入桌面，但会在约 1–2 秒内被重新锁定。
