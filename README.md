# 手机健康助手 · 老年人用机时长守护

一个面向安卓手机的用机时长守护工具：累计亮屏使用达到上限后，手机会自动锁屏；休息倒计时结束前，每次解锁都会被立即重新锁定，倒计时结束后恢复正常使用。语音通话、来电、短信与闹钟全程不受影响。

锁屏页对长辈显示的是「手机运行内存不足，正在自动清理」的善意提示（而不是"你被管控了"），减少抵触情绪；应用内的设置页则使用正常表述，方便家属管理。

## 功能特性

- **时长守护**：单次连续使用达上限自动锁屏，休息倒计时结束自动恢复。
- **善意锁屏文案**：全屏显示"内存清理"倒计时，避免被当作管控软件。
- **紧急拨号**：锁屏页保留拨号入口，且只放行电话界面，不放任整机使用。
- **通话不受影响**：来电、去电、响铃全程暂停计时与锁屏。
- **局域网远程控制**：家属用浏览器即可查看状态、临时解锁、调整时长，无需服务器或账号。
- **隐藏桌面图标**：图标可隐藏，守护在后台继续运行。
- **开机自启 + 心跳保活**：重启或被清理后自动恢复。

## 一、构建

本仓库已包含完整的 Gradle Wrapper，无需单独安装 Gradle。

### 命令行

需要 JDK 17 与 Android SDK 34：

```bash
./gradlew assembleDebug
```

Windows 下用 `gradlew.bat assembleDebug`。

产物路径：`app/build/outputs/apk/debug/app-debug.apk`

### Android Studio

用 Android Studio（Giraffe 及以上）打开本目录，等待 Gradle Sync，然后运行 `app` 模块，或 `Build > Build Bundle(s)/APK(s) > Build APK(s)`。

- compileSdk / targetSdk = 34，minSdk = 24（Android 7.0 起可装）
- 构建工具：Gradle 8.7（Wrapper 已随仓库提供）

## 二、安装后的权限配置（关键）

安装后打开应用，在首页逐项授权：

| 权限 | 作用 | 必要性 |
| --- | --- | --- |
| 设备管理器 | 调用系统 `lockNow()` 锁屏 | 必需，否则只能提醒无法锁屏 |
| 悬浮窗 | 全屏显示休息倒计时 | 强烈推荐，否则只弹通知 |
| 通知（Android 13+） | 显示守护状态 | 推荐 |
| 忽略电池优化 | 防止后台被系统杀掉 | 强烈推荐 |
| 使用情况访问 | 让「紧急拨号」只放行电话界面 | 推荐 |

只申请了「强制锁屏」一项设备管理能力，**不会清除数据**。

### 小米 / Redmi（澎湃 OS、MIUI）额外设置

小米系 ROM 后台限制严格，务必手动开启以下三项，否则会出现"装了不生效"（不是闪退，而是后台服务被杀）：

1. **自启动**：设置 → 应用设置 → 应用管理 → 手机健康助手 → 自启动 → 打开
2. **省电策略**：同页面 → 省电策略 → 选「无限制」
3. **后台弹出界面**：同页面 → 权限管理 → 后台弹出界面 → 允许

华为 / OPPO / vivo 类似：允许自启动、锁定后台、关闭耗电保护。

## 三、使用步骤（给家里老人装一次即可）

1. 打开应用 → 点「激活设备管理器（重要）」，在系统弹窗里点「激活」。
2. 点「开启悬浮窗提醒（重要）」并允许。
3. Android 13+ 授予「通知」权限；再点「忽略电池优化」。
4. 点「开启使用情况访问（推荐）」，在系统列表里找到本应用并允许（用于紧急拨号只放行电话界面）。
5. 首页可调两件事：单次连续使用上限（10–120 分钟）、休息时长（5–60 分钟）。
6. 保持「开启守护」打开即可，重启手机后会自动恢复。

## 四、局域网远程控制（给家属用）

手机与家属的设备连在同一个 WiFi 时，用浏览器就能管理，不需要服务器、账号或云服务：

1. 打开应用首页，在「远程控制」卡片里会显示形如 `http://192.168.1.5:8899/?key=662704` 的地址。
2. 用家里另一台手机或电脑的浏览器打开该地址（密钥已带在链接里）。
3. 页面上可以：
   - 查看守护状态、本轮已用时长、今日累计、休息剩余时间；
   - 临时解锁 15 / 30 / 60 分钟（期间即使超过上限也不锁屏，到点自动恢复）；
   - 修改单次使用上限（10–120 分钟）与休息时长（5–60 分钟）；
   - 暂停或重新开启守护。
4. 所有接口都校验 `key`，密钥错误返回 403。密钥随机生成，保存在应用私有配置里。

注意：只能在同一个局域网内访问；手机换 WiFi 后 IP 会变，重新打开首页查看新地址即可。

## 五、工作方式

| 阶段 | 行为 |
| --- | --- |
| 正常使用 | 每 5 秒累计一次屏幕点亮时长；息屏、通话中都不计时 |
| 达到上限 | 立即锁屏，全屏显示「手机运行内存不足」与清理倒计时（善意的表述，避免被当作管控软件），期间不计时 |
| 休息期间 | 用户解锁后先停留 20 秒（首次）或 8 秒（再次解锁），期间显示全屏倒计时与「紧急拨号」；缓冲结束若仍在休息期就再次锁定 |
| 休息结束 | 停止锁屏，本次时长归零，重新开始一轮计数 |
| 关闭开关 | 立即结束本轮锁定，重新计时 |

## 六、紧急拨号：只放行电话界面

锁屏 / 休息页留有「紧急拨号」入口，点击后：

- **已授予「使用情况访问」权限**：停留在拨号、联系人、通话界面期间**不限时**放行；一旦切到其它 App，立即取消放行并恢复锁定。
- **未授予该权限**：系统无法识别前台界面，只给约 **45 秒**拨号窗口，超时恢复锁定。
- **通话过程中持续续期**，挂断后保留约 **20 秒**缓冲，避免刚挂断就被锁回去。
- 只有确认拨号界面真的能打开，才会开始放行，避免长辈白白拿到一段自由使用时间。

来电界面天然优先于悬浮窗，接听、挂断都不受限制；锁屏只影响屏幕，不影响短信接收、闹钟和后台通信。

## 七、隐藏桌面图标与恢复

首页「隐藏桌面图标」可将图标从桌面隐藏，守护在后台继续运行。隐藏后如需恢复，连接电脑执行：

```bash
adb shell am broadcast -a com.anxin.guard.SHOW_LAUNCHER
```

再次隐藏：

```bash
adb shell am broadcast -a com.anxin.guard.HIDE_LAUNCHER
```

## 八、如何卸载

因为激活了设备管理器，系统会阻止直接卸载。需先取消激活：

1. 设置 → 安全 → 更多安全设置 → 设备管理应用（各厂商路径略有差异）
2. 找到「手机健康助手」→ 取消激活
3. 回到应用列表正常卸载

建议先在应用内关闭「开启守护」。

## 九、项目结构

```
app/src/main/java/com/anxin/guard/
├── MainActivity.kt          # 设置页：权限引导、时长调整、远程控制卡片、隐藏图标
├── GuardService.kt          # 常驻前台服务：计时状态机、锁屏、紧急拨号放行

├── OverlayController.kt     # 全屏"内存清理"倒计时与紧急拨号入口
├── GuardDeviceAdmin.kt      # 设备管理器（lockNow）
├── BootReceiver.kt          # 开机/换包自启 + 心跳保活闹钟
├── RemoteControlServer.kt   # 局域网 HTTP 控制服务（端口 8899）
├── AppVisibility.kt         # 前台应用 / 使用情况访问检测（紧急拨号放行依据）
├── Prefs.kt                 # 配置持久化（含远程密钥）
├── Notifications.kt         # 状态与提醒通知
├── GuardApp.kt              # Application：图标显隐广播桥接
├── LauncherAlias.kt         # 桌面图标别名（运行时禁用即隐藏图标）
└── Format.kt                # 时间格式化
```

## 十、快速验证（不用等 40 分钟）

把「单次连续使用上限」拖到 10 分钟、「休息时长」拖到 5 分钟，然后：

1. 保持亮屏使用，状态卡里的分钟数逐步上升；
2. 10 分钟后手机自动锁屏，唤醒后看到全屏倒计时；
3. 尝试解锁，首次会看到全屏倒计时，约 20 秒后才再次锁定；点「紧急拨号」进入拨号界面，停留期间不锁屏，切到其它 App 立即恢复锁定；
4. 5 分钟后唤醒，可正常进入桌面；
5. 期间打一通电话，验证休息期间仍能正常接打。

## 十一、已知限制

- 必须先激活设备管理器，否则只能显示全屏提醒，无法锁屏。
- 用户可以在系统设置中停用设备管理器或强行停止本应用，这是普通应用无法阻止的；如需彻底防绕过，需要把手机设为设备所有者（Device Owner），会要求恢复出厂设置，不适合日常使用。
- 部分厂商（华为、小米、OPPO、vivo）的省电策略可能杀掉后台，务必按「二、安装后的权限配置」开启自启动、无限制省电、后台弹出界面。
- 手机未设置锁屏密码时，唤醒后可短暂进入桌面，但会在约 1–2 秒内被重新锁定。
